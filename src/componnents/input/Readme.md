How to use it 
<<<
    <Input />
>>>

@! Props
@: margin: margin around it ( MUI )  
@: id: id of input component,
@: error: for validation if it's true border turn to red and show error text,
@: label: label for input,
@: autoFocus: boolean,
@: onlyNumber: boolean,
@: required: put * before title,
@: sx: sx style from ( MUI ),
@: size: two size from ( MUI ),
@: InputLabelProps: controle the label props ( MUI ),
@: autoComplete: string,
@: fullWidth: boolean,
@: name: default name for html input element,
